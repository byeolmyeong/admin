# 002. 점검 상태 하나만 화면 틀이 받아서 모든 화면에 알린다

> 상태: 활성 · 결정일 2026-11-12 · 001 의 "화면마다 받아서 그린다" 에 예외 하나를 더한다(001 은 그대로 활성)

## 맥락
- 서버에 점검(`PUT /admin/app-config/maintenance`, 서버 결정 017)이 생겼다. 켜져 있으면 모든 사용자가 앱과 웹을 쓸 수 없다.
- 계약은 "켜져 있는 동안 눈에 띄게 보여 준다" 를 권한다. 앱 설정 화면에만 보이면 다른 화면을 보는 관리자가 켜 둔 것을 잊는다.
- 001 은 서버 상태를 화면마다 받아서 그리고, 전역 상태 라이브러리를 쓰지 않기로 했다.

## 결정
- **점검이 켜져 있는지(`maintenance.active`) 한 값만** 화면 틀(`AppShell`)이 가진다. 라이브러리는 더하지 않는다 — React 컨텍스트 하나(`src/features/app-config/MaintenanceContext.tsx`)다.
- 받는 때: 로그인한 뒤 화면 틀이 뜰 때 `GET /admin/app-config` 한 번. 그 뒤로는 앱 설정 화면이 받아 오거나 저장한 값을 알려 줄 때만 바뀐다(주기적으로 다시 묻지 않는다).
- 켜져 있으면 화면 틀이 모든 화면 위에 "점검 중" 띠와 앱 설정으로 가는 링크를 보인다. 받지 못했으면 띠를 보이지 않는다(오류는 앱 설정 화면이 알린다).
- 그 밖의 서버 상태는 001 그대로 화면마다 받는다.

## 버린 대안
- 화면마다 `GET /admin/app-config` — 모든 화면에 같은 코드가 들어가고 화면을 옮길 때마다 부른다.
- 주기적으로 다시 받기 — 다른 관리자가 켠 것도 곧 보이지만, 관리자 몇 명이 쓰는 화면에 타이머를 둘 만큼은 아니다. 필요해지면 다시 본다.

## 영향
- 다른 관리자가 켜거나 끈 것은 새로 고치거나 앱 설정 화면을 열 때까지 띠에 반영되지 않는다.
